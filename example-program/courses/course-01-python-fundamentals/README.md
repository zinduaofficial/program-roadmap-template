# Course 1: Python Fundamentals

> **Part of:** [Software Engineering Program](../../README.md)  
> **Duration:** 6 weeks  
> **Level:** Beginner  
> **Prerequisites:** None - this is the starting course

## Course Overview

Python Fundamentals introduces students to programming through Python, one of the most beginner-friendly and versatile programming languages. This course builds a strong foundation in programming concepts, problem-solving, and computational thinking.

Students start with basic syntax and progress to more advanced topics like object-oriented programming and algorithms. Through hands-on coding exercises, projects, and pair programming sessions, students develop the skills and confidence needed for software development.

By the end of this course, students will be comfortable writing Python programs, understanding code written by others, and applying programming concepts to solve real-world problems.

## Learning Objectives

By the end of this course, students will be able to:

1. **Understanding & Knowledge**
   - Explain core programming concepts (variables, data types, control flow)
   - Understand how programs execute and how to trace code
   - Describe object-oriented programming principles

2. **Technical Skills**
   - Write clean, readable Python code following PEP 8 style guidelines
   - Implement common data structures (lists, dictionaries, sets)
   - Create and use functions, classes, and modules
   - Handle errors and exceptions gracefully
   - Read from and write to files

3. **Application & Problem-Solving**
   - Break down complex problems into manageable steps
   - Choose appropriate data structures for different scenarios
   - Debug code using systematic approaches
   - Implement basic algorithms (sorting, searching)
   - Analyze algorithm efficiency using Big O notation

## Core Topics

### 1. Python Basics
- Python installation and setup
- Interactive shell vs. scripts
- Variables and naming conventions
- Data types (int, float, string, bool)
- Operators (arithmetic, comparison, logical)
- Input and output
- String formatting

### 2. Control Flow & Functions
- Conditional statements (if, elif, else)
- Boolean logic and compound conditions
- Loops (while, for)
- Loop control (break, continue)
- Functions and parameters
- Return values
- Scope and namespaces
- Lambda functions

### 3. Data Structures
- Lists and list methods
- Tuples and immutability
- Dictionaries and key-value pairs
- Sets and set operations
- List comprehensions
- Dictionary comprehensions
- Choosing the right data structure

### 4. Files & Modules
- Reading and writing text files
- CSV and JSON file handling
- Exception handling (try, except, finally)
- Raising exceptions
- Importing modules
- Creating custom modules
- Python standard library

### 5. Object-Oriented Programming
- Classes and objects
- Attributes and methods
- Constructors and initialization
- Encapsulation
- Inheritance and super()
- Polymorphism
- Magic methods
- Class vs. instance attributes

### 6. Algorithms & Complexity
- Algorithm analysis basics
- Big O notation
- Linear and binary search
- Sorting algorithms (bubble, insertion, merge)
- Recursion principles
- Base cases and recursive cases
- Space vs. time complexity

## Projects

### Project 1: Number Guessing Game
**Type:** Individual  
**Duration:** Week 2  
**Focus:** Control flow, functions, user input

Build an interactive command-line game where the computer generates a random number and the player tries to guess it. Include difficulty levels, scoring, and high scores saved to a file.

**Key Requirements:**
- Random number generation
- User input validation
- Difficulty levels (easy, medium, hard)
- Score tracking and persistence
- Replay functionality

[View full project details](projects/number-guessing-game.md)

### Project 2: Contact Management System
**Type:** Individual  
**Duration:** Week 4  
**Focus:** Data structures, file I/O, CRUD operations

Create a command-line application to manage contacts with the ability to add, view, update, delete, and search contacts. Data should persist in a file.

**Key Requirements:**
- CRUD operations for contacts
- File-based data persistence (JSON)
- Search and filter functionality
- Input validation and error handling
- User-friendly command-line interface

[View full project details](projects/contact-manager.md)

### Project 3: Text Adventure Game
**Type:** Individual  
**Duration:** Week 6  
**Focus:** Object-oriented programming, design

Design and build a text-based adventure game using OOP principles. Include multiple rooms, items, characters, and a compelling storyline.

**Key Requirements:**
- Class hierarchy (Room, Character, Item, Player)
- Inheritance and polymorphism
- Game state management
- Command parser
- Win/lose conditions

[View full project details](projects/text-adventure.md)
