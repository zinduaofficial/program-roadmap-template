# Week 1: Python Basics

> **Course:** Python Fundamentals  
> **Week:** 1 of 6  
> **Duration:** 40 hours of study

## Overview

Welcome to your first week of Python programming! This week introduces the fundamental building blocks of Python: variables, data types, operators, and basic input/output. You'll write your first Python programs and learn how to interact with users through the command line.

## Learning Objectives

By the end of this week, students will be able to:
- Install Python and set up a development environment
- Write and execute Python scripts
- Use variables to store and manipulate data
- Work with different data types (integers, floats, strings, booleans)
- Perform operations using various operators
- Get input from users and display output
- Format strings for better readability

## Key Takeaways

At the end of this week, students should understand:

1. **Variables are containers for data:** They store values that can be used and manipulated throughout your program.
2. **Python has dynamic typing:** You don't need to declare types explicitly; Python figures it out.
3. **Operators let you perform actions:** From math calculations to logical comparisons, operators are essential tools.
4. **Strings are versatile:** Python provides powerful tools for working with text data.
5. **Interactive programs use input/output:** The input() and print() functions enable user interaction.

## Common Challenges & Tips

**Challenge 1:** Forgetting to convert input() to the right type  
**Tip:** Remember that input() always returns a string. Use int() or float() to convert numbers.

**Challenge 2:** String indexing confusion  
**Tip:** Python uses 0-based indexing. The first character is at index 0, not 1.

**Challenge 3:** Operator precedence  
**Tip:** When in doubt, use parentheses to make your intentions clear and control order of operations.

## Glossary

**Variable:** A named storage location for data that can change during program execution.  
**Data Type:** The classification of data which determines what operations can be performed on it.  
**Operator:** A symbol that performs an operation on one or more operands.  
**String:** A sequence of characters used to represent text.  
**Integer:** A whole number without a decimal point.  
**Float:** A number with a decimal point.  
**Boolean:** A data type with two possible values: True or False.  
**REPL:** Read-Eval-Print Loop, an interactive programming environment.
