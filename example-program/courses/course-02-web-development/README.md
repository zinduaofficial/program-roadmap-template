# Course 2: Web Development

> **Part of:** [Software Engineering Program](../../README.md)  
> **Duration:** 8 weeks  
> **Level:** Beginner to Intermediate  
> **Prerequisites:** Python Fundamentals (Course 1) or equivalent programming experience

## Course Overview

Web Development introduces students to building modern, responsive web applications. This comprehensive course covers both frontend and backend development, starting with the fundamentals of HTML, CSS, and JavaScript, then progressing to modern frameworks and full-stack development.

Students learn to create beautiful, interactive user interfaces and powerful backend APIs. By combining frontend and backend skills, students build complete web applications ready for deployment. The course emphasizes best practices, responsive design, and industry-standard tools.

By the end of this course, students will have built multiple web applications and understand the entire web development stack from design to deployment.

## Learning Objectives

By the end of this course, students will be able to:

1. **Frontend Development**
   - Create semantic, accessible HTML structures
   - Style responsive websites with modern CSS techniques
   - Build interactive user interfaces with JavaScript
   - Develop single-page applications using React
   - Consume RESTful APIs from the frontend

2. **Backend Development**
   - Build RESTful APIs with Node.js and Express
   - Handle HTTP requests and responses
   - Implement basic authentication and authorization
   - Connect to databases and perform CRUD operations
   - Deploy web applications to production

3. **Full-Stack Integration**
   - Connect frontend and backend systems
   - Handle asynchronous operations
   - Manage application state effectively
   - Debug across the full stack
   - Follow web development best practices

## Core Topics

### 1. HTML5 & Web Fundamentals
- Semantic HTML elements
- Document structure and metadata
- Forms and input validation
- Accessibility (ARIA, semantic tags)
- SEO basics

### 2. CSS3 & Styling
- CSS selectors and specificity
- Box model and positioning
- Flexbox and Grid layouts
- Responsive design with media queries
- CSS animations and transitions
- CSS custom properties (variables)
- Modern CSS features

### 3. JavaScript Essentials
- ES6+ syntax (let, const, arrow functions)
- Data types and structures
- Functions and scope
- DOM manipulation
- Event handling
- Asynchronous JavaScript (promises, async/await)
- Fetch API and HTTP requests
- Error handling

### 4. React Framework
- React fundamentals and JSX
- Components (functional and class)
- Props and prop types
- State and useState hook
- useEffect and lifecycle
- React Router
- Form handling in React
- Context API and state management

### 5. Backend Development
- Node.js runtime
- Express.js framework
- RESTful API design
- HTTP methods and status codes
- Middleware and request processing
- Basic authentication
- Environment variables
- CORS and security basics

### 6. Full-Stack Integration
- Connecting React to Express APIs
- Handling API responses
- Error handling across stack
- Environment configuration
- Deployment strategies
- Production vs. development

**Duration:** Week 2  
**Focus:** HTML, CSS, responsive design

**Key Requirements:**
- Semantic HTML structure
- Responsive design (mobile, tablet, desktop)
- Modern CSS with Flexbox/Grid

### Project 2: Weather Dashboard
**Type:** Individual  
**Duration:** Week 4  
**Focus:** JavaScript, APIs, async programming

Create an interactive weather dashboard that fetches real-time weather data from an API and displays it with a clean interface.

**Key Requirements:**
- Fetch data from OpenWeather API
- Search for cities
- Display current weather and forecast
- Error handling for failed requests
- Save favorite cities to localStorage

**Type:** Individual

**Key Requirements:**
- React frontend with routing
- Express REST API backend
- CRUD operations for blog posts
- User authentication (basic)
- Responsive design
