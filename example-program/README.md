# Software Engineering Program - 6 Months

> **Status:** Active  
> **Level:** Beginner to Intermediate  
> **Format:** Full-time

## Program Overview

The Software Engineering Program is an intensive 6-month bootcamp designed to transform beginners into job-ready software engineers. Students learn full-stack web development, software engineering best practices, and modern development workflows through hands-on projects and real-world applications.

This program combines theoretical foundations with practical application, ensuring students not only understand how to code but also how to think like engineers, work in teams, and build production-ready applications.

## Program Goals

By the end of this program, students will be able to:
- Design, develop, and deploy full-stack web applications
- Write clean, maintainable, and well-tested code
- Work effectively in agile development teams
- Use modern development tools and workflows
- Debug and solve complex technical problems
- Build a professional portfolio of projects

## Target Audience

This program is designed for:
- Career changers looking to enter the tech industry
- Recent graduates seeking practical software development skills
- Self-taught developers wanting structured learning and mentorship
- Professionals looking to upskill in modern web technologies

**Prerequisites:** Basic computer literacy and strong problem-solving skills. No prior programming experience required.

## Program Structure

**Duration:** 24 weeks (6 months)  
**Time Commitment:** 40+ hours per week (full-time)  
**Number of Courses:** 4 main courses + capstone project

### Curriculum Overview

The program is divided into 4 main phases:

1. **Phase 1: Programming Fundamentals** (6 weeks)
   - Focus: Python programming, algorithms, and problem-solving
   - Outcome: Strong foundation in programming concepts

2. **Phase 2: Web Development** (8 weeks)
   - Focus: Frontend and backend web development
   - Outcome: Ability to build full-stack web applications

3. **Phase 3: Advanced Topics** (6 weeks)
   - Focus: Database design, APIs, testing, and DevOps
   - Outcome: Production-ready development skills

4. **Phase 4: Capstone Project** (4 weeks)
   - Focus: Building a complete application from scratch
   - Outcome: Portfolio-worthy project and interview preparation

## Projects

Throughout the program, students will complete:

- **8+ Individual Projects** - Building specific skills
- **3 Group Projects** - Collaborative development experience
- **1 Capstone Project** - Comprehensive final project

Major projects include:

1. **Command-Line Game** (Python Fundamentals) - Build an interactive text-based game
2. **Personal Portfolio Website** (Web Development) - Create a responsive personal website
3. **Task Management App** (Web Development) - Full-stack CRUD application
4. **E-commerce Platform** (Capstone) - Complete online store with payment integration

## Prerequisites

Before starting this program, students should:

- High school diploma or equivalent

- Basic computer literacy (file management, web browsing)

**Recommended:**
