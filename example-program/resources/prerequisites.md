# Prerequisites

> **Program:** Software Engineering Program

## Overview

This document outlines the prerequisites and recommended preparation for the Software Engineering Program. Meeting these prerequisites will help ensure you're ready to succeed in this intensive 6-month bootcamp.

## Required Prerequisites

These are essential prerequisites that students **must** have before starting the program:

### 1. Educational Background

**Requirement:**
- High school diploma or equivalent
- Strong reading and writing skills in English
- Basic mathematics (algebra level)

**Why it matters:**
Programming involves logical thinking and problem-solving skills that build on basic educational foundations. You'll need to read technical documentation, write clear code, and understand mathematical concepts for algorithms.

### 2. Computer Literacy

**Requirement:**
- Comfortable navigating file systems (creating folders, moving files)
- Experience using web browsers and online tools
- Ability to install and configure software
- Basic understanding of how the internet works

**Why it matters:**
You'll be working extensively with development tools, command-line interfaces, and online resources. Basic computer skills are essential for the learning process.

**How to verify you have this:**
- Can you find a file on your computer without help?
- Do you understand the difference between downloading and installing software?
- Can you manage browser bookmarks and tabs effectively?

### 3. Problem-Solving Aptitude

**Requirement:**
- Ability to break complex problems into smaller steps
- Comfort with logical thinking and puzzles
- Persistence when facing challenges
- Willingness to learn through trial and error

**Why it matters:**
Programming is fundamentally about solving problems. A strong problem-solving mindset is more important than any prior technical knowledge.

**How to verify you have this:**
- Do you enjoy puzzles, brain teasers, or strategy games?
- Can you follow multi-step instructions?
- Are you comfortable trying different approaches when something doesn't work?

## Recommended Prerequisites

While not strictly required, having these will make your learning experience smoother:

### 1. Basic Programming Exposure

**Helpful to have:**
- Completed an introductory programming tutorial (Codecademy, freeCodeCamp, Khan Academy)
- Written a few simple programs in any language
- Understanding of basic concepts like variables, loops, and functions

**How it helps:**
While we teach from the ground up, having seen these concepts before makes the learning curve less steep and lets you focus more on application.

### 2. Typing Skills

**Helpful to have:**
- Touch typing ability (at least 30-40 WPM)
- Comfort with keyboard shortcuts

**How it helps:**
You'll be typing code for many hours each day. Better typing skills mean less frustration and faster development.

### 3. Time Management Skills

**Helpful to have:**
- Experience managing multiple deadlines
- Ability to create and follow schedules
- Self-discipline for independent study

**How it helps:**
This intensive program requires strong time management. You'll balance lectures, projects, and self-study simultaneously.

## Technical Requirements

### Hardware

**Minimum:**
- Computer with 8GB RAM (16GB strongly recommended)
- 256GB available storage space
- Webcam and microphone for remote sessions
- Stable internet connection (5 Mbps minimum)

**Recommended:**
- 16GB+ RAM for running multiple development tools
- 512GB SSD for faster performance
- External monitor for increased productivity
- Backup internet connection option

### Software

**Required:**
- Windows 10/11, macOS 10.15+, or Ubuntu 20.04+ LTS
- Modern web browser (Chrome, Firefox, or Edge - latest version)
- Ability to install software without restrictions

**Recommended:**
- Administrative access to your computer
- Cloud storage account (Google Drive, Dropbox, etc.)

### Internet Connection
- Minimum 5 Mbps download, 2 Mbps upload
- Reliable connection for video calls and cloud-based tools
- Mobile hotspot as backup recommended

## Time Commitment

**Expected Weekly Commitment:**
- 40+ hours per week for full-time program
- Available during standard business hours (9 AM - 5 PM local time) for synchronous sessions

**Be prepared to:**
- Attend 20-25 hours of live instruction per week
- Spend 15-20 hours on assignments and projects
- Dedicate 5+ hours for self-study and practice
- Participate in study groups and code reviews

**Important:** This is an intensive, full-time commitment. Part-time work or other major commitments during the program can negatively impact your success.

## Self-Assessment

Before starting the program, check if you can:

### Computer Skills
- [ ] Create and organize folders on your computer
- [ ] Install new software applications
- [ ] Use keyboard shortcuts (copy, paste, save)
- [ ] Search effectively using Google
- [ ] Navigate using the command line (helpful but not required)

### Problem-Solving
- [ ] Break a large task into smaller steps
- [ ] Follow written technical instructions
- [ ] Debug simple issues (like why something won't install)
- [ ] Learn new concepts from written tutorials
- [ ] Persist when facing challenges

### Time Management
- [ ] Commit to 40+ hours per week for 6 months
- [ ] Manage multiple deadlines simultaneously
- [ ] Study independently without constant supervision
- [ ] Ask for help when stuck

**Scoring:**
- If you checked 80% or more: You're ready to start!
- If you checked 60-79%: Review the areas you're unsure about
- If you checked less than 60%: Strongly consider working through the preparatory resources first

## Bridging Gaps

### If you're missing Basic Programming Knowledge:
**Option 1:** Complete freeCodeCamp's first 20 hours of content  
**Option 2:** Take CS50x Week 0-1 and do the problem sets  
**Timeline:** 2-4 weeks of preparation

### If you lack Computer Literacy:
**Option 1:** Take a basic computer skills course (library, community college)  
**Option 2:** Practice with online tutorials (GCFGlobal.org)  
**Timeline:** 1-2 weeks of focused practice

### If Time Commitment is an Issue:
**Option 1:** Defer to a future cohort when you have more time  
**Option 2:** Ensure you have no other major commitments during the program  
**Timeline:** Plan your schedule 1-2 months in advance

## Frequently Asked Questions

**Q: What if I don't meet all the prerequisites?**  
A: Contact our admissions team to discuss your situation. We may recommend preparatory work or suggest deferring to a future cohort.

**Q: Can I start the program while building missing prerequisites?**  
A: Not recommended. The program moves quickly, and gaps in foundational skills make it very difficult to keep up.

**Q: How strictly are prerequisites enforced?**  
A: We want you to succeed! These prerequisites are based on what successful students typically have. If you're close but unsure, talk to us.

**Q: Where can I get help assessing my readiness?**  
A: Schedule a call with our admissions team, or attend an open house/info session where you can ask questions.

**Q: I've never programmed before. Can I still succeed?**  
A: Yes! Many successful graduates started with no programming experience. The key is meeting the other prerequisites (problem-solving, time commitment, computer literacy) and being ready to learn intensively.
