# Software Engineering Program - Full Curriculum

## Program Overview

**Duration:** 24 weeks (6 months)  
**Total Hours:** 960+ hours (40+ hours/week)  
**Format:** Full-time, intensive bootcamp

## Curriculum Structure

This curriculum is organized into 4 courses covering 24 weeks of instruction.

---

## Course 1: Python Fundamentals

**Duration:** 6 weeks  
**Hours:** 240 hours

### Course Overview
Introduction to programming using Python. Students learn fundamental programming concepts, data structures, algorithms, and object-oriented programming through hands-on coding exercises and projects.

### Learning Objectives
By the end of this course, students will:
- Write clean, efficient Python code following best practices
- Implement common data structures and algorithms
- Apply object-oriented programming principles
- Debug and test Python applications
- Solve problems using computational thinking

### Topics Covered
- **Week 1:** Python basics, variables, data types, operators
- **Week 2:** Control flow, functions, scope
- **Week 3:** Data structures (lists, dictionaries, sets, tuples)
- **Week 4:** File I/O, error handling, modules
- **Week 5:** Object-oriented programming (classes, inheritance, polymorphism)
- **Week 6:** Algorithms, recursion, complexity analysis

### Projects
1. **Number Guessing Game** - Interactive command-line game with scoring
2. **Contact Management System** - CRUD application using file storage
3. **Text Adventure Game** - Object-oriented game with multiple classes

### Assessment
- Weekly coding assignments (40%)
- Three projects (45%)
- Code reviews and pair programming (15%)

---

## Course 2: Web Development

**Duration:** 8 weeks  
**Hours:** 320 hours

### Course Overview
Comprehensive introduction to modern web development. Students learn both frontend and backend development, building responsive websites and dynamic web applications using industry-standard tools and frameworks.

### Learning Objectives
By the end of this course, students will:
- Build responsive, accessible web interfaces
- Create interactive web applications with JavaScript
- Develop RESTful APIs with Node.js
- Integrate frontend and backend systems
- Deploy web applications to production

### Topics Covered
- **Week 1:** HTML5 fundamentals and semantic markup
- **Week 2:** CSS3, Flexbox, Grid, responsive design
- **Week 3:** JavaScript basics and DOM manipulation
- **Week 4:** ES6+ features, async programming, fetch API
- **Week 5:** React fundamentals, components, props, state
- **Week 6:** React hooks, routing, state management
- **Week 7:** Node.js, Express.js, REST API design
- **Week 8:** Full-stack integration, authentication basics

### Projects
1. **Portfolio Website** - Responsive personal website with modern CSS
2. **Weather Dashboard** - React app consuming external APIs
3. **Blog Platform** - Full-stack CRUD application with React frontend and Express backend

### Assessment
- Weekly assignments and code challenges (30%)
- Three major projects (50%)
- Code reviews and presentations (20%)

---

## Course 3: Advanced Software Engineering

**Duration:** 6 weeks  
**Hours:** 240 hours

### Course Overview
Advanced topics in software engineering including database design, testing, version control workflows, and deployment. Students learn professional development practices and how to work effectively in teams.

### Learning Objectives
By the end of this course, students will:
- Design and implement relational databases
- Write comprehensive tests for applications
- Use Git workflows for team collaboration
- Deploy and monitor production applications
- Follow agile development practices

### Topics Covered
- **Week 1:** SQL and relational database design
- **Week 2:** PostgreSQL, ORMs, database optimization
- **Week 3:** Testing (unit, integration, end-to-end)
- **Week 4:** Git workflows, code review, CI/CD
- **Week 5:** Docker, environment management
- **Week 6:** Deployment, monitoring, performance optimization

### Projects
1. **Database Design Challenge** - Design schema for complex application
2. **Testing Workshop** - Add comprehensive tests to existing codebase
3. **Team Project** - Collaborative development with Git workflows and CI/CD

### Assessment
- Technical assignments (30%)
- Team project (50%)
- Code reviews and collaboration (20%)

---

## Course 4: Capstone Project

**Duration:** 4 weeks  
**Hours:** 160 hours

### Project Overview
Students design and build a complete full-stack web application from scratch, incorporating all skills learned throughout the program. Projects are chosen to showcase students' abilities and serve as portfolio pieces.

### Requirements
- Full-stack application using learned technologies
- User authentication and authorization
- Database with at least 3 related models
- RESTful API
- Responsive frontend interface
- Deployed to production
- Comprehensive documentation
- Test coverage

### Deliverables
- Working application deployed online
- Source code on GitHub
- README with project overview and setup
- Technical documentation
- 10-minute presentation and demo
