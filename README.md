# Program Roadmap Template

This template is designed for showcasing open-source curriculum and roadmaps for tech programs at Zindua School. It provides a standardized structure to present program details, course outlines, learning objectives, and projects—without sharing the actual course content.

## Purpose

This template helps us:
- **Share program structure transparently** with students, partners, and the community
- **Showcase curriculum design** and learning pathways
- **Highlight projects and practical work** students will complete
- **Maintain content security** by separating structure from actual teaching materials

## Repository Structure

```
program-name/
├── README.md                 # Program overview
├── CURRICULUM.md             # Full curriculum outline
├── courses/
│   ├── course-01-name/
│   │   ├── README.md        # Course details
│   │   ├── modules/
│   │   │   ├── week-01.md   # Weekly/module breakdown
│   │   │   ├── week-02.md
│   │   │   └── ...
│   │   └── projects/
│   │       ├── project-1.md # Project specifications
│   │       └── project-2.md
│   └── course-02-name/
│       └── ...
└── resources/
    ├── prerequisites.md      # Prerequisites for the program
    ├── tools-setup.md        # Development environment setup
    └── learning-paths.md     # Suggested learning paths
```

## How to Use This Template

### For Program Creators

1. **Fork or copy this repository** for your specific program
2. **Rename the directory** from `example-program` to your program name
3. **Update the program README** with your program's details
4. **Create course folders** for each course in your program
5. **Fill in course details** using the provided templates
6. **Add modules and projects** following the template structure
7. **Update CONTRIBUTING.md** with program-specific guidelines

### For Students and Community

- Browse the curriculum to understand what topics are covered
- Review learning objectives for each course and module
- See project requirements to understand practical applications
- Check prerequisites and setup requirements before starting

## Template Files

This repository includes the following templates:

- **`templates/PROGRAM_README.md`** - Main program landing page template
- **`templates/CURRICULUM.md`** - Full curriculum overview template
- **`templates/COURSE_README.md`** - Individual course overview template
- **`templates/MODULE.md`** - Weekly/module content outline template
- **`templates/PROJECT.md`** - Project specification template
- **`templates/PREREQUISITES.md`** - Prerequisites documentation template

## What to Include vs. Exclude

### ✅ Include (Public)
- Program and course descriptions
- Learning objectives and outcomes
- Topic lists and skill areas
- Project requirements and specifications
- Prerequisites and recommended preparation
- Assessment criteria (general guidelines)
- Weekly/module structure and pacing
- Tools and technologies used

### ❌ Exclude (Private)
- Lecture notes and slides
- Video content and recordings
- Detailed lesson plans
- Exercise solutions and answer keys
- Test questions and answers
- Internal grading rubrics
- Student submissions and work
- Licensed or proprietary content
